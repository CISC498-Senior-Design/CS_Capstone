PERSISTENT NOTE TAKING APP:

An AI-powered meeting note-taking application designed to help users capture discussions, generate summaries, and preserve important information from meetings.

HIGHLIGHTS
__________________________________________________________________________________________________________________________________________________________________

-Meeting Recording: Capture meeting audio for note-taking.

-Speech-to-Text Transcription: Convert recorded audio into readable text.

-AI-Powered Summaries: Generate concise meeting summaries from transcripts.

-Editable Notes: Review, correct, and refine AI-generated summaries before saving.

-Persistent Notes: Keep meeting notes organized for future reference.

-Google Docs Integration: Transfer approved summaries into Google Docs while preserving existing document formatting.


OVERVIEW
__________________________________________________________________________________________________________________________________________________________________

This Persistent Note Taking App is our senior design project developed to simplify meeting documentation and make important discussions easier to revisit. The application aims to record meeting audio, generate transcripts, and use AI to create summaries that preserve the original discussion's meaning and tone. Users will be able to review and edit generated notes before approving them for integration into Google Docs. The goal is to reduce the manual effort involved in taking meeting notes while helping users retain important information and action items.
